## 2. Gaps of this search
- WebSearch/WebFetch were not used (general web search, Google Scholar, the Lean Zulip and mailing lists not searched); conference proceedings (ITP, CICM, ADG, ThEdu) were searched only through the arXiv API.
- GitHub code search covers only default branches and caps results (rate limit 10/min; the queries that hit the limit were re-run). Repositories with geometry under non-standard names may be missed.
- AFP: only the geometry topic page (36 entries) was checked; theories outside that topic were not grepped. The HOL Light `Multivariate` tree was checked by file name and one code search, not theorem by theorem. Mizar was not searched (beyond Wiedijk's list). GeoCoq was checked by file names and the quadrilateral lemma list.
- External files were read, not compiled.
- The fast-growing AI-proof collections (lean-genius, atlas-lean, ShadowBench, Principia math-solutions, The-Last-Math-Competition, LeanPool) were checked by full tree listing for the first three; Principia, TLMC and LeanPool only through global code search.
