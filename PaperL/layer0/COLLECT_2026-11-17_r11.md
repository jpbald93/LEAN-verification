**Target B — the projective level point:**

```lean
noncomputable def EptInf (n : ℕ) (c : Fin n → ℂ) : OnePoint ℂ :=
  if crossVec (KP n c c̄) ⟨n / 2⟩ = 0 then OnePoint.infty else ↑(levelPointN n (crossVec (KP n c c̄)))

theorem EptInf_eq_infty  (h : v ⟨n/2⟩ = 0) : EptInf n c = ∞
theorem EptInf_eq_coe    (h : v ⟨n/2⟩ ≠ 0) : EptInf n c = Ept n c
theorem EptInf_c6       : EptInf 6 c6 = ∞                       -- A and B tied together
theorem h4_pt_inf : GenPosN c → ChainS 4 c {EptInf 4 c}          -- via crossVec_KP4_P2_ne_zero + h4_pt
theorem hc_of_genPos {n} (hn : 2 ≤ n) : GenPosN c → ∀ j, c j ≠ 0
```

The `if` is non-dependent, and the finite branch is **syntactically** the body of `Ept`, so `EptInf_eq_coe` is
`if_neg h` — the content of B is the *definition*, not the lemma. `hc_of_genPos` needed the extra `2 ≤ n`: at
`n = 1` general position is vacuous and `c 0 = 0` is allowed, so the brief's signature without it was false. The job
said so instead of silently weakening the statement.
