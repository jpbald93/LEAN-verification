# LEAN-verification — supporting material for the AFM Lean papers

Supporting material for the papers by Josh Bald (ORCID 0009-0002-1317-6489) on formal proofs of classical geometry and number theory in Lean 4 with Mathlib. One folder per paper; each folder has its own README listing the Lean code repositories and commits, the verification reports, fresh-clone receipts, review records, the hand-check sheet where present, the Layer-14/15 records, and the complete zip archives as originally prepared (`zip/`).

| Folder | Paper |
|---|---|
| [`Baranyai`](Baranyai/) | Baranyai's theorem on factorisations of complete uniform hypergraphs, formalised in Lean 4 with Mathlib |
| [`Casey-Fuss`](Casey-Fuss/) | Casey's theorem and Fuss's theorem, formalised in Lean 4 with Mathlib |
| [`Cayley-Bacharach`](Cayley-Bacharach/) | The Cayley–Bacharach theorem for plane cubics, formalised in Lean 4, with finite-field thresholds |
| [`Conics-dandelin-marden`](Conics-dandelin-marden/) | Dandelin spheres and Marden's theorem, formalised in Lean 4 |
| [`PaperA-coordinate-certificates`](PaperA-coordinate-certificates/) | Classical plane geometry by coordinate certificates: Desargues, Monge, Simson, Napoleon and Lami in Lean 4 |
| [`PaperB-feuerbach-miquel-brahmagupta-malfatti`](PaperB-feuerbach-miquel-brahmagupta-malfatti/) | The Malfatti circles in Lean 4, with independent certificate proofs of Feuerbach, Miquel and Brahmagupta |
| [`PaperC-barbier-four-vertex`](PaperC-barbier-four-vertex/) | Barbier's theorem for the Reuleaux triangle and the convex four-vertex theorem in Lean 4, through support functions |
| [`PaperD-circle-configurations`](PaperD-circle-configurations/) | Circle configurations in classical plane geometry, formalized in Lean 4: Clifford's chain, Miquel's five circles, Lester, Sawayama–Thébault and Kosnita |
| [`PaperE-complete-quadrilateral`](PaperE-complete-quadrilateral/) | The complete quadrilateral in Lean 4: Newton–Gauss, Bodenmiller, the Miquel point, the Steiner circle and the Simson line |
| [`PaperF-inscribed-parabola-poncelet-point`](PaperF-inscribed-parabola-poncelet-point/) | The inscribed parabola and the Poncelet point: the complete quadrilateral and the complete quadrangle in Lean 4 |
| [`PaperG-triangle-centres`](PaperG-triangle-centres/) | Triangle centres in Lean 4: the Nagel line family and the symmedian and Brocard points |
| [`PaperH-triangle-inequalities`](PaperH-triangle-inequalities/) | Classical triangle inequalities and the Fermat–Napoleon configuration in Lean 4 |
| [`Pascal-Brianchon`](Pascal-Brianchon/) | Pascal's hexagon theorem over an arbitrary field, formalised in Lean 4 |
| [`Primitive-root-families`](Primitive-root-families/) | Primitive roots modulo primes 2^kℓ+1, formalised in Lean 4: Chebyshev's base-10 criterion and the least primitive root of a safe prime |
| [`Triangle-Simplex`](Triangle-Simplex/) | Five classical theorems on triangles and simplices, formalised in Lean 4 with Mathlib: Carnot, Viviani, De Gua, the Japanese theorem and Poncelet's porism |

The Lean code itself is in separate repositories under https://github.com/jpbald93 (linked from each folder's README). Machine names, IP addresses and home-directory paths are redacted throughout. Each folder has a `SHA256SUMS.txt`.
